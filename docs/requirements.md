# 錯視立体ジェネレーター＆ビューア 要件定義書

## 1. プロジェクト概要

### 1.1 プロジェクト名（仮）

Ambiguous 3D Studio

### 1.2 目的・背景

射影幾何学および CSG（Constructive Solid Geometry）演算を活用し、異なる 2〜3 方向からの投影シルエットを満たす「錯視立体（両義立体）」をブラウザ上でリアルタイムに合成・体験・出力できる Web アプリケーションを構築する。

### 1.3 プロジェクトスコープ

- **コア（Main）**: 2D シルエット入力に基づく 3D 錯視立体の自動メッシュ生成、3D プリンタ用 STL エクスポート。
- **サブ（Sub）**: ブラウザ上での視点合わせゲーム（Sweet Spot 検知）、仮想ミラー表示、ゼロインストール WebAR 体験。
- **非スコープ**: ユーザー認証、サーバーサイド DB 保存、有料決済機能（完全クライアントサイド完結型 SPA）。

## 2. システム構成 & 技術スタック

| レイヤー / 領域 | 採用技術 | 選定理由・責務 |
|---|---|---|
| フロントエンド | Vite + React + TypeScript | 型安全な幾何データパイプライン構築、高速な SPA 動作 |
| 3D レンダリング | Three.js / React Three Fiber (`@react-three/fiber`, `@react-three/drei`) | WebGL 描画、カメラ・ライト制御、React State と描画サイクルの分離 |
| 幾何・CSG 演算 | manifold-3d (Wasm) または three-bvh-csg | 2D パス押し出し立体のブール交差演算、閉多様体（Watertight）の保証 |
| UI コンポーネント | Tailwind CSS + Lucide React | ミニマルな設定パネル、レスポンシブレイアウト |
| AR モジュール | `@google/model-viewer` | iOS（Quick Look: USDZ）/ Android（Scene Viewer: GLB）での WebAR 起動 |
| エクスポート | STLExporter / GLTFExporter | クライアントメモリ上でのバイナリ STL / GLB ファイル生成とダウンロード |

## 3. 機能要件 (Functional Requirements)

### F-1. 幾何シルエット入力モジュール (Input)

- **F-1.1 プリセット図形選択**
  - 円、正方形、正三角形、ハート、星、矢印、十字などの基本 2D ベクター図形を即座に選択可能とする。
- **F-1.2 テキスト入力（文字押し出し）**
  - ユーザーが任意の英数字（1 文字〜複数文字）を入力し、フォントのアウトラインパスから立体を生成する。
- **F-1.3 SVG カスタムインポート**
  - ユーザー所有の SVG ファイルをアップロードし、閉じたパス（Closed Path）を抽出してシルエットとして使用する。
- **F-1.4 投影軸・角度設定**
  - 視点 A（正面: Z 軸）、視点 B（側面: X 軸、または斜め 45 度・上面: Y 軸）の直交・斜交関係を指定可能とする。

### F-2. メッシュ生成 & CSG 演算エンジン (Generation)

- **F-2.1 2D パスの 3D 押し出し成形 (Extrusion)**
  - 各シルエットから視線ベクトル方向に沿った柱状体メッシュ（Extruded Mesh）を生成する。
- **F-2.2 ブール交差演算 (CSG Intersection)**
  - 2 つ（または 3 つ）の柱状体の共通集合 `M = M_A ∩ M_B` をブール交差演算によってリアルタイムに算出する。
- **F-2.3 3D プリント補助構造（台座・サポート）の付与**
  - 交差によって分離したパーツが存在する場合の警告表示。
  - オプションとして、底面に一体成形用のフラット台座（Baseplate）をブール和（Addition）で結合する機能。

### F-3. インタラクティブ 3D ビューア & 錯視体験 (Viewer & Play)

- **F-3.1 自由視点操作**
  - OrbitControls による直感的な 360 度回転、パン、ズーム操作（減衰アニメーション付き）。
- **F-3.2 視点スナップ**
  - 「正面（視点 A）」「側面（視点 B）」「俯瞰（Isometric）」ボタンにより、正解アングルへカメラを即座に移動する。
- **F-3.3 スウィートスポット（Sweet Spot）検知**
  - カメラの視線ベクトル `c_vec` と目標視線ベクトル `v_A`, `v_B` の角度差 θ をリアルタイム計測。
  - 許容誤差 θ < 3.5°（約 0.06 rad）を満たした際に、UI 上に「シルエット合致」のインジケーター / エフェクトを表示する。
- **F-3.4 仮想ミラープレビュー (Virtual Mirror)**
  - オブジェクト後方に反射面（鏡）を配置し、視点 A から「本体の形」と「鏡に映る形（視点 B）」が同時に成立する光景をシミュレーション表示する。

### F-4. WebAR 機能 (AR Module)

- **F-4.1 メモリ内モデルシリアライズ**
  - 生成された BufferGeometry を動的に GLB（Android 向け）および USDZ（iOS 向け）バイナリ Blob へ変換する。
- **F-4.2 ゼロインストール AR 起動**
  - スマホブラウザ上で AR 起動ボタンを押すことで、専用アプリなしで机上等に 1:1 スケールで立体を配置し、周囲を歩いて錯視を確認可能とする。

### F-5. エクスポート機能 (Export)

- **F-5.1 STL ファイル出力**
  - 3D スライサー（Bambu Studio, PrusaSlicer, Cura 等）に直接読み込み可能なバイナリ形式の `.stl` をワンクリックでダウンロード。
- **F-5.2 GLTF/GLB ファイル出力**
  - CG ソフト（Blender 等）や Web 共有用のマテリアル情報付き `.glb` ファイルをダウンロード。

## 4. 非機能要件 (Non-Functional Requirements)

### 4.1 性能要件 (Performance)

- **CSG 演算レイテンシ**: ユーザーの入力変更（図形選択・文字変更）からメッシュ再生成・描画完了まで **300ms 以内** を達成すること。
- **描画フレームレート**: 3D ビューポートのカメラ操作時は常時 **60fps** を維持すること（演算ステート更新とレンダリングサイクルの分離）。

### 4.2 幾何学的堅牢性 (Mesh Quality)

- **マニホールド性（Watertight）**: 3D プリント出力時にスライスエラーが発生しないよう、交差演算後のメッシュは穴や裏返り面のない閉多様体（2-Manifold）を担保すること。

### 4.3 互換性 (Compatibility)

- **対象ブラウザ**: Google Chrome, Apple Safari, Mozilla Firefox, Microsoft Edge（いずれも最新版・WebGL 2.0 対応環境）。
- **モバイル対応**: iOS Safari（iOS 15 以上）および Android Chrome におけるレスポンシブ表示と AR 起動。

### 4.4 セキュリティ & プライバシー

- ユーザーが入力したテキストやアップロードした SVG データは一切外部サーバーへ送信せず、すべてクライアントブラウザのメモリ内でのみ処理する。

### 5.2 主要インタラクションフロー

- **初期状態**: デフォルトで「四角」×「円」の交差立体が俯瞰アングルで表示される。
- **形状変更**: 左パネルで視点 A/B の形状を変更すると、即座に 3D モデルがモーフィング / 再計算される。
- **視点探索**:
  - 手動ドラッグでカメラを回し、正面または側面に角度が近づくとインジケーターが「合致！」に変化。
  - 「正面 (A)」「側面 (B)」ボタンを押すことで、各錯視シルエットの正解位置へカメラが自動吸着。
- **出力**: 「STL 出力」ボタンを押すと、即座にブラウザのダウンロード処理が実行される。

## 6. 開発フェーズ・マイルストーン

- **Phase 1 (MVP - コア生成・描画)**
  - プリセット図形同士の直交 CSG 交差パイプライン実装。
  - R3F ビューポート、OrbitControls、バイナリ STL ダウンロード機能。
- **Phase 2 (UX 向上 & 錯視演出)**
  - テキスト入力（TrueType Font パス押出）および SVG インポート対応。
  - 視点スナップアニメーション、Sweet Spot 判定インジケーター、仮想ミラー実装。
- **Phase 3 (WebAR & 最適化)**
  - `<model-viewer>` を用いた GLB / USDZ の動的生成と WebAR 起動。
  - 複雑パス交差時の CSG 高速化（Web Worker 化または manifold-3d Wasm 完全結合）。
